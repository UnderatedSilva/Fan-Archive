Project: Dhanith Sri — Figma Mockup Starter

Goal
- Create a Figma-ready mockup inspired by the layout and visual language of landonorris.com, adapted for Dhanith Sri.

Scope (first iteration)
- Hero: oversized typographic treatment with layered purple shapes and large name.
- Section headers: bold, tightly tracked, large scale.
- Songs grid: card tiles with purple accents.
- Awards / Stats strip: numeric highlights.

Deliverables in this repo
- `figma-tokens.json` — color, typography, spacing tokens for Figma.
- `prototype.html` — lightweight HTML prototype to use as a reference when building frames in Figma.
- `assets/hero.svg` — scalable hero artwork to import into Figma.
